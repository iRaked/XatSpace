## ✨ Descripción

**Xat Space** es una colección de obras originales diseñadas para personalizar perfiles en [xat.com](https://xat.com). Estas fueron mis primeras creaciones en este entorno, y representan el inicio de una trayectoria técnica y simbólica que continúa hasta hoy.

Actualmente mantengo contacto con la mayoría de los clientes originales, y cada perfil ha sido actualizado con mejoras en **practicidad** y **responsividad**, sin alterar la esencia de las obras.  
Las estructuras originales se mantienen intactas: solo se han modernizado para adaptarse a nuevos dispositivos y estándares.
